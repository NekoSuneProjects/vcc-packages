# Changelog

## 1.1.0

- Standalone package: no longer needs the NekoSune World Hub (`com.nekosune.worlds`). The window keeps its own look and opens from NekoSune → World → Image Gallery.
- In-editor update checker: clickable version chip next to the header and an update banner (Download / Later / Skip this version).
- NekoSuneVR footer with social links (Twitch, X, YouTube, Bluesky, Discord, Patreon, Ko-fi).
- Fixed: the shader transitions (Wipe, Dissolve, Radial) used `ZTest Always` and drew through walls and other world geometry; they now use the standard UI depth test.
