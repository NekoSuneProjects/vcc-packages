# Changelog

## 1.0.0

- First release as a VCC/VPM package (`com.nekosune.beat-keyframing`).
- Waveform plus frequency-band lanes, detected bass drops, estimated beat grid; follows Unity's Animation window and plays audio in sync.
- In-editor update checker: version chip in the toolbar (amber when an update is out) and a slim update row with Download / Later / Skip this version.
- NekoSuneVR footer: an **NS** toolbar button opens it as a popup, and it shows at the bottom of the empty timeline before a clip is loaded, so the visualizer keeps its full height.
- Installing the package removes only the old `Assets/NekoSuneVR/NekoBeatKeyframing/Editor` folder; imported audio is kept.
