# Changelog

## 2.0.0

- First release as a VCC/VPM package (`com.nekosune.motion-converter`).
- Modular tabs: Generic FBX / .anim, Fortnite (.ueanim) and MMD / VMD (body + camera).
- Artist / Title output layout under `Assets/[Motions Converted]`.
- 10 UI languages and the NekoSuneVR about bar.
- Installing the package removes an old `Assets/MotionConverter` copy automatically.
