# Changelog

## 2.0.0

- First release as a VCC/VPM package (`com.nekosune.intro-idle-audio`), depending on the VRChat Avatars SDK.
- Three windows: the Intro + Idle Audio hub, the Avatar Intro Installer and the AFK Idle Audio Installer.
- In-editor update checker: clickable version badge in each window's header and an update banner (Download / Later / Skip this version).
- NekoSuneVR footer with social links (Twitch, X, YouTube, Bluesky, Discord, Patreon, Ko-fi).
- Installing the package removes an old `Assets/NekoSuneVR/VRChatIdleAudioInstaller` copy. Generated output in `Assets/NekoSuneVR/Generated/IntroIdleAudio` is kept, and existing particle materials keep their shader.
