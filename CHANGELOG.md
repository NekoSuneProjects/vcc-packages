# Changelog

## 2.1.0

- First release as a VCC/VPM package (`com.nekosune.multi-publisher`), depending on the VRChat Avatars SDK 3.10+.
- In-editor update checker: the version chip in the header is clickable and turns amber when an update is out; an update banner offers Download / Later / Skip this version.
- Installing the package removes an old `Assets/NekoSuneMultiPublisher` copy. Saved accounts (`%LOCALAPPDATA%\NekoSuneVR\MultiPublisher`) and avatar IDs (`UserSettings/NekoSuneMultiPublisher`) live outside it and are kept.
