Getting started

Install in three steps

  1. 1

    Add the repository

    Click Add to VCC, or paste the repository URL into the Creator Companion under Settings → Packages.

  2. 2

    Pick your packages

    Open your project in VCC and add the hub for your project type - Avatar or World — plus any addons you want.

  3. 3

    Open the hub

    In Unity use the NekoSune menu. Installed addons register in their hub automatically.
